# Перенос базы с Render на Neon

Бесплатная база PostgreSQL на Render удаляется через 30 дней: у NUMMAZA срок истекает **10 декабря 2026**. Neon бесплатный без срока (0,5 ГБ, база засыпает без запросов и просыпается за пару секунд). Перенос занимает около 15 минут, данные пользователей не теряются.

## 1. Создать базу в Neon (делаете вы)

1. Зарегистрируйтесь на [neon.tech](https://neon.tech) через GitHub.
2. Create project → имя `nummaza`, PostgreSQL 17, регион **AWS Europe Central (Frankfurt)**: там же работает сервер на Render, запросы будут быстрыми.
3. На странице проекта нажмите **Connect** и скопируйте строку подключения вида `postgresql://…@…neon.tech/neondb?sslmode=require`.

Строка подключения — это пароль к базе. Не отправляйте её в чат и не сохраняйте в репозиторий.

## 2. Перенести данные

Нужна строка подключения к **старой** базе: Render → `nummaza-db` → Connect → **External Database URL**.

На компьютере в папке проекта (PowerShell):

```powershell
cd server
npm ci
$env:FROM_URL = "строка старой базы Render (External)"
$env:TO_URL   = "строка новой базы Neon"
node scripts/migrate-db.mjs
```

Скрипт создаёт таблицы в Neon и копирует все данные с теми же id: аккаунты, сессии, операции, семьи, подписки на уведомления. Затем переносит счётчик синхронизации, чтобы телефоны продолжили с того же места, и сверяет количество строк. Старую базу он только читает. Если связь оборвалась, просто запустите его снова: дублей не будет. В конце должно быть «Готово: все таблицы перенесены».

Чтобы ничего не изменилось во время переноса, перед запуском можно поставить сервер на паузу: Render → `nummaza` → Settings → Suspend. После переноса нажмите Resume.

## 3. Переключить сервер на Neon

1. Render → сервис `nummaza` → **Environment** → `DATABASE_URL` → вставьте строку Neon → Save. Render перезапустит сервер.
2. Откройте `https://nummaza.onrender.com/api/health`: там должно быть `{"ok":true}` (сервер ответил и база доступна).
3. Войдите в приложение своим аккаунтом и проверьте, что операции на месте.

В `render.yaml` у `DATABASE_URL` стоит `sync: false`: Render больше не подставляет туда старую базу, значение задаётся только в панели.

## 4. Удалить старую базу

Когда всё работает (например, через день), удалите базу `nummaza-db` в Render и блок `databases:` в `render.yaml`.
