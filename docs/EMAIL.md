# Почта и push-уведомления (версия 1.3)

Без этих настроек приложение работает. Не работают только две вещи:
- восстановление пароля: письмо с кодом не уходит, код появляется в логе сервера;
- push-напоминания на сайте и на iPhone. В Android-приложении напоминания работают и без них: их ставит сам телефон.

## Письма с кодом — Brevo (бесплатно, 300 писем в день)

1. Зарегистрируйтесь на [brevo.com](https://www.brevo.com).
2. **Senders, Domains & Dedicated IPs → Senders → Add a sender**: имя `NUMMAZA`, адрес, с которого придут письма (можно ваш Gmail). Подтвердите адрес по ссылке из письма Brevo.
3. **SMTP & API → API Keys → Generate a new API key** → скопируйте ключ (`xkeysib-…`).
4. Render → сервис `nummaza` → **Environment**:
   - `BREVO_API_KEY` — ключ из шага 3;
   - `MAIL_FROM` — подтверждённый адрес из шага 2.
5. Save. Чтобы проверить: выйдите из приложения → «Забыли пароль?» → введите телефон аккаунта, к которому в «Профиле» привязана почта. Через минуту придёт письмо с 6-значным кодом (проверьте и «Спам»).

С адреса Gmail письма иногда попадают в «Спам». Когда появится свой домен (например, nummaza.kz), подтвердите его в Brevo (Domains) и отправляйте с `no-reply@nummaza.kz`.

Ключ API — это пароль. Вставляйте его только в Render, не в чат и не в репозиторий.

## Push-напоминания на сайте и iPhone — ключи VAPID

1. На компьютере в папке проекта:
   ```powershell
   cd server
   npx web-push generate-vapid-keys
   ```
2. Render → `nummaza` → **Environment**:
   - `VAPID_PUBLIC_KEY` — Public Key;
   - `VAPID_PRIVATE_KEY` — Private Key (секрет);
   - `VAPID_SUBJECT` — `mailto:` и ваш адрес, например `mailto:you@example.com`.
3. Save. В приложении: «Профиль» → «Напоминания» → «Включить уведомления».

На iPhone push работает с iOS 16.4, и только когда NUMMAZA добавлена на экран «Домой». Ключи меняйте только при утечке: после смены все пользователи заново нажимают «Включить уведомления».
